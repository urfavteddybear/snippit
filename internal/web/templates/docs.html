API

Create and read pastes from scripts and the terminal. No account or API key needed.

Quick start

curl -s {{.BaseURL}}/api/pastes \
  -H 'Content-Type: application/json' \
  -d '{"title":"hello.js","content":"console.log(1)","language":"auto","expiration":"1d"}'

Pipe a file with jq:

jq -Rs '{content: ., expiration: "7d"}' app.log | curl -s {{.BaseURL}}/api/pastes -H 'Content-Type: application/json' -d @-

Endpoints

POST/api/pastes

FieldTypeNotes
contentstringRequired. UTF-8 text, at most {{bytes (int64 .MaxBytes)}}.
titlestringOptional, at most 120 characters.
languagestringauto (default) or a language ID below.
expirationstring{{range $i, $e := .Expirations}}{{if $i}}, {{end}}{{$e.Key}}{{end}}. Default 7d.
passwordstringOptional. Encrypts the content at rest.
delete_keystringOptional. Lets anyone who knows it delete the paste.

Returns 201 Created:

{
  "id": "a8Kx92LmQ3",
  "url": "{{.BaseURL}}/a8Kx92LmQ3",
  "raw_url": "{{.BaseURL}}/raw/a8Kx92LmQ3",
  "language": "javascript",
  "expires_at": 1794000000,
  "deletion_token": "…"
}

expires_at is a Unix timestamp (UTC), or null for pastes that never expire. deletion_token also deletes the paste and is never shown again. Keep it if you did not set a delete_key.

GET/api/pastes/:id

Returns metadata and content as JSON. For a password-protected paste, send the password in the X-Paste-Password header.

GET/raw/:id

Returns the original content as text/plain. Password-protected pastes also accept X-Paste-Password.

curl -s {{.BaseURL}}/raw/a8Kx92LmQ3 | sh   # read it before you run it

GET/download/:id

Same as raw, served as a file attachment.

DELETE/api/pastes/:id

Deletes a paste. Send either the delete key you chose in X-Delete-Key, or the deletion_token from the create response in X-Delete-Token. Returns 204 No Content.

curl -X DELETE {{.BaseURL}}/api/pastes/a8Kx92LmQ3 -H 'X-Delete-Key: my-secret-key'
