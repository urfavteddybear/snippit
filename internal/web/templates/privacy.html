Privacy

Snippit is built to collect as little as possible.

What we store

  • The paste content, title, language, creation time and expiration time.
  • A hash of the deletion token, and a slow hash of the delete key if you set one. Neither is stored in plain text.
  • For password-protected pastes, the content is encrypted with a key derived from your password. The password is never stored. The title is not encrypted.

What we don't collect

  • No accounts, emails, or profiles.
  • No analytics, tracking scripts, or third-party requests. Fonts and scripts are served from this site.
  • No public listing of pastes. A paste is reachable only by its link.
  • The History page is kept in your browser's local storage and is never sent to the server.

IP addresses and logs

Your IP address is held in memory for a few minutes to enforce rate limits. It is not written to the database or to application logs. Application logs record the request method, path, status code and timing, never paste content.

The operator's reverse proxy may keep standard access logs, subject to the operator's retention settings.

Retention

A paste is kept until it expires or is deleted by its creator. Expired pastes are removed from the database by a periodic cleanup job.

Deleting a paste removes it from the live database right away. Database backups made before the deletion may still contain it until those backups are rotated.

Anyone with the link can read it

Paste links are long and random, but they are not secret by themselves. Use a password for anything sensitive, and avoid pasting credentials.
